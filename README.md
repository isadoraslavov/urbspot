# UrbSpot – Guia Interativo de Eventos e Cultura Urbana em Brasília

Aplicação web desenvolvida para a disciplina de **Desenvolvimento de Interfaces** (HTML5, CSS3 e JavaScript Vanilla), com foco em acessibilidade, usabilidade e identidade visual inspirada na cultura urbana e no grafite de Brasília.

## Acesse o Projeto Online
🔗 **[(https://isadoraslavov.github.io/urbspot/)]**

## Tecnologias Utilizadas
- HTML5 Semântico e Acessibilidade (ARIA)
- CSS3 (Flexbox, Grid, Temas Claro/Escuro e Alto Contraste)
- JavaScript Vanilla (ES6+) e LocalStorage
